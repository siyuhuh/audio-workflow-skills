# VocalFlow v0.8.0-beta.4

中文 | [English](#english)

这是一个预发布测试版。桌面安装包已经包含默认处理流程需要的运行时、工具和模型，下载安装后即可使用，不需要另外安装 Python、Homebrew、FFmpeg 或默认模型。

## 选择安装包

| 下载文件 | 适用设备 | 大小 |
| --- | --- | ---: |
| `VocalFlow-0.8.0-beta.4-mac-arm64.dmg` | Apple Silicon Mac；推荐的原生 K 歌客户端 | 约 997 MB |
| `VocalFlow.Studio-0.8.0-beta.4-mac-arm64.dmg` | Apple Silicon Mac；制作、检查与播放工作台 | 约 411 MB |
| `VocalFlow.Studio-0.8.0-beta.4-win-x64.exe` | 64 位 Windows；制作、检查与播放工作台 | 约 377 MB |

目前没有 Intel Mac 安装包。iPhone 版本仍处于 TestFlight / Xcode 测试流程，本次 Release 不包含 iPhone 安装包。

## 模型、联网与空间

- 默认内置 `faster-whisper-small`（约 464–486 MB）和 `UVR-MDX-NET-Inst_HQ_3.onnx`（约 64 MB），合计约 527 MB，不会在首次处理时重复下载。
- Studio 的“高级”设置可选更大的 Whisper 模型；第一次使用时会从 Hugging Face 下载并缓存在本机：`medium` 约 1.53 GB、`large-v3-turbo` 约 1.62 GB、`large-v3` 约 3.09 GB。
- 本地文件处理、已导入歌曲包播放和录音可以离线完成。媒体链接下载、在线搜索与可选模型首次下载需要网络。
- 建议至少预留 5 GB 可用空间；使用 `large-v3` 或保留较多 MV / 中间文件时建议预留 10 GB 以上。

## 首次打开

安装包尚未使用 Developer ID 签名和 Apple 公证。macOS 首次启动时，可在 Finder 右键应用选择“打开”，或前往“系统设置 → 隐私与安全性 → 仍要打开”。如果系统提示应用“已损坏”，确认安装包来自本 Release 后执行：

```bash
xattr -dr com.apple.quarantine "/Applications/VocalFlow.app"
# VocalFlow Studio 使用：
xattr -dr com.apple.quarantine "/Applications/VocalFlow Studio.app"
```

Windows SmartScreen 出现时，选择“更多信息 → 仍要运行”。

## 本版亮点

- 原生 Mac Room、跨平台 VocalFlow Studio、iPhone 客户端与私有 Mac mini Agent 使用兼容的 K 歌包流程。
- 原生 Mac 与 Studio 均支持演唱录音：麦克风 WAV 原始人声，以及可分享的 M4A / MP3 / WAV 混音。
- Studio 增加录音电平、录音预览、重命名、增益 / 延迟调整和重新导出。
- 自适应 MV、逐字歌词、原唱 / 伴奏切换、队列、YouTube 和哔哩哔哩来源。
- Python 运行时、处理依赖、`ffmpeg`、`yt-dlp` 和默认模型随桌面安装包提供。

# English

This is a prerelease. Desktop installers include the runtime, tools, and default models required by the standard workflow. You can use the app after installation without separately installing Python, Homebrew, FFmpeg, or a default model.

## Choose an installer

| Download | Platform | Size |
| --- | --- | ---: |
| `VocalFlow-0.8.0-beta.4-mac-arm64.dmg` | Apple Silicon Mac; recommended native karaoke client | About 997 MB |
| `VocalFlow.Studio-0.8.0-beta.4-mac-arm64.dmg` | Apple Silicon Mac; creation, review, and playback studio | About 411 MB |
| `VocalFlow.Studio-0.8.0-beta.4-win-x64.exe` | 64-bit Windows; creation, review, and playback studio | About 377 MB |

There is no Intel Mac installer yet. The iPhone client is still distributed through the TestFlight/Xcode beta workflow and is not included in this Release.

## Models, network access, and storage

- `faster-whisper-small` (about 464–486 MB) and `UVR-MDX-NET-Inst_HQ_3.onnx` (about 64 MB) are bundled, about 527 MB total. The default workflow does not download them again on first use.
- Larger Whisper models are available in Studio's Advanced settings and download from Hugging Face on first use: `medium` about 1.53 GB, `large-v3-turbo` about 1.62 GB, and `large-v3` about 3.09 GB.
- Local-file processing, imported-package playback, and recording can work offline. Media URL downloads, online search, and the first optional-model download require network access.
- Keep at least 5 GB free, or 10 GB or more when using `large-v3` or retaining many MVs and intermediate files.

## First launch

The installers are not yet Developer ID signed or Apple-notarized. On macOS, right-click the app in Finder and choose **Open**, or use **System Settings → Privacy & Security → Open Anyway**. If macOS says the app is damaged, first verify that it came from this Release, then run:

```bash
xattr -dr com.apple.quarantine "/Applications/VocalFlow.app"
# For VocalFlow Studio:
xattr -dr com.apple.quarantine "/Applications/VocalFlow Studio.app"
```

On Windows, choose **More info → Run anyway** if SmartScreen appears.

## Highlights

- The native Mac Room, cross-platform VocalFlow Studio, iPhone client, and private Mac mini Agent share a compatible karaoke-package workflow.
- Native Mac and Studio both support performance recording: raw vocal WAV plus a share-ready M4A/MP3/WAV mix.
- Studio adds recording meters, take preview, rename, gain/latency adjustment, and re-export.
- Adaptive MV display, word-synced lyrics, original/backing selection, queue, YouTube, and Bilibili sources.
- Python runtime, processing dependencies, `ffmpeg`, `yt-dlp`, and default models ship inside desktop installers.
