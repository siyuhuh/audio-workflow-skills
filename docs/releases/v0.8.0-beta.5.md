# VocalFlow v0.8.0-beta.5

中文 | [English](#english)

这是一个面向干净电脑安装测试的修复版。beta.4 的 VocalFlow Studio 安装包遗漏了默认模型，首次分离时会转而访问 Hugging Face，并可能触发匿名下载限流；beta.5 已修复这个打包问题。

桌面安装包现在包含 Python 运行时、处理依赖、`ffmpeg`、`yt-dlp`、默认 Whisper 小模型和 UVR 人声分离模型。默认流程下载安装后即可使用，不需要 Python、Homebrew、HF Token 或额外模型下载。

## 选择安装包

| 下载文件 | 适用设备 | 大小 |
| --- | --- | ---: |
| `VocalFlow-0.8.0-beta.5-mac-arm64.dmg` | Apple Silicon Mac；推荐的原生 K 歌客户端 | 约 995 MB |
| `VocalFlow.Studio-0.8.0-beta.5-mac-arm64.dmg` | Apple Silicon Mac；制作、检查与播放工作台 | 约 920 MB |
| `VocalFlow.Studio-0.8.0-beta.5-win-x64.exe` | 64 位 Windows；制作、检查与播放工作台 | 约 874 MB |

目前没有 Intel Mac 安装包。iPhone 版本不包含在本次 GitHub Release。

## 本版修复

- 正式 Studio macOS / Windows 打包配置现在包含 `faster-whisper-small` 与 `UVR-MDX-NET-Inst_HQ_3.onnx`。
- 新增发布后内部检查：Python、FFmpeg、处理脚本或任一默认模型缺失 / 体积异常时，CI 会阻止 Release 发布。
- Separate 阶段改为持续活动状态，不再在无法计算百分比时一直误显示 0%。
- 默认工作流不会访问 Hugging Face；HF Token 仅在用户主动选择可选大模型时需要考虑。

## 模型、联网与空间

- 内置 `faster-whisper-small`（约 464–486 MB）和 `UVR-MDX-NET-Inst_HQ_3.onnx`（约 64 MB）。
- Studio 可选模型首次使用时仍需下载：`medium` 约 1.53 GB、`large-v3-turbo` 约 1.62 GB、`large-v3` 约 3.09 GB。
- 本地文件处理、已导入歌曲包播放和录音可以离线完成；YouTube / 哔哩哔哩媒体下载和在线搜索仍需要网络。
- 建议至少预留 5 GB；使用大模型或保留较多 MV / 中间文件时建议 10 GB 以上。

## 首次打开

安装包尚未使用 Developer ID 签名和 Apple 公证。macOS 首次启动时，可在 Finder 右键应用选择“打开”，或前往“系统设置 → 隐私与安全性 → 仍要打开”。Windows SmartScreen 出现时，选择“更多信息 → 仍要运行”。

# English

This is a clean-machine installation fix. VocalFlow Studio beta.4 accidentally omitted the default model files, so first separation fell back to Hugging Face and could hit anonymous-download rate limits. Beta.5 fixes the packaging error.

Desktop installers now contain the Python runtime, processing dependencies, `ffmpeg`, `yt-dlp`, the default Whisper small model, and the UVR separator model. The default workflow is ready after installation without Python, Homebrew, an HF Token, or an additional model download.

## Choose an installer

| Download | Platform | Size |
| --- | --- | ---: |
| `VocalFlow-0.8.0-beta.5-mac-arm64.dmg` | Apple Silicon Mac; recommended native karaoke client | About 995 MB |
| `VocalFlow.Studio-0.8.0-beta.5-mac-arm64.dmg` | Apple Silicon Mac; creation, review, and playback studio | About 920 MB |
| `VocalFlow.Studio-0.8.0-beta.5-win-x64.exe` | 64-bit Windows; creation, review, and playback studio | About 874 MB |

There is no Intel Mac installer yet. The iPhone client is not included in this GitHub Release.

## Fixes

- Production Studio packaging for macOS and Windows now includes `faster-whisper-small` and `UVR-MDX-NET-Inst_HQ_3.onnx`.
- CI inspects the packaged app and blocks publishing if Python, FFmpeg, the processing script, or either default model is missing or unexpectedly small.
- The Separate stage now shows continuous indeterminate activity instead of a misleading 0% when fractional progress is unavailable.
- The default workflow does not contact Hugging Face. An HF Token only becomes relevant when the user explicitly selects an optional larger model.

## Models, network access, and storage

- Bundled: `faster-whisper-small` (about 464–486 MB) and `UVR-MDX-NET-Inst_HQ_3.onnx` (about 64 MB).
- Optional Studio models still download on first use: `medium` about 1.53 GB, `large-v3-turbo` about 1.62 GB, and `large-v3` about 3.09 GB.
- Local-file processing, imported-package playback, and recording can work offline. YouTube/Bilibili media downloads and online search still require network access.
- Keep at least 5 GB free, or 10 GB or more when using larger models or retaining many MVs and intermediate files.

## First launch

The installers are not yet Developer ID signed or Apple-notarized. On macOS, right-click the app in Finder and choose **Open**, or use **System Settings → Privacy & Security → Open Anyway**. On Windows, choose **More info → Run anyway** if SmartScreen appears.
