# VocalFlow v0.8.0-beta.10

中文 | [English](#english)

这是第一个使用 Developer ID 签名并通过 Apple 公证的 VocalFlow Studio。拖进“应用程序”后双击即可打开，不需要再右键“打开”或到“隐私与安全性”里放行。

本版汇总了 beta.5 之后的全部改进：修复了搜索正常但 Add 失败的问题，歌词会先和本地识别比对再采用，处理中断或部分失败后可以恢复，手机遥控页改为中文优先。安装包仍包含 Python 运行时、处理依赖、`ffmpeg`、`yt-dlp`、默认 Whisper 小模型和 UVR 人声分离模型，下载安装后即可使用，不需要 Python、Homebrew、HF Token 或额外模型下载。

这是预发布测试版，干净电脑上的安装验收仍在进行。

## 本版变化

**安装与打开**
- 使用 Developer ID 签名并通过 Apple 公证，公证票据已附在 DMG 上。
- 修复 beta.5 中下载器和分离器带有构建机器路径、导致搜索正常但 Add 失败的问题；补齐 `audioread` 和分离模型配置文件。
- Electron 升级到 44.8.0，并更新了有安全公告的依赖。

**歌词**
- KTV 模式不再因为有平台字幕而跳过人声分离。
- 自动模式优先使用与歌曲语言匹配的人工字幕，并用本地识别检查内容和大致时间；内容不符时改用识别草稿，只有时间错位时保留文字并标记需要检查。

**中断与失败后的恢复**
- 点歌队列在重启后保留；被中断的任务标记为失败，等你处理，不会自动重跑。
- 用相同设置重试时，只有在输入、模型和输出都校验通过后才复用已完成的人声分离。
- 人声分离已完成而歌词失败时，伴奏仍保留在曲库里，可以无歌词进入 KTV；任务依然显示失败，可以重试。
- 取消的任务不算完成，失败的重做不会覆盖已有的完整歌曲。

**手机遥控**
- 扫码打开的遥控页改为搜索优先，默认中文，可一键切到英文并记住选择。

**提示**
- 来源网站返回 HTTP 403 时，不再误报为需要登录。

## 模型、联网与空间

- 内置 `faster-whisper-small`（约 484 MB）和 `UVR-MDX-NET-Inst_HQ_3.onnx`（约 67 MB）。
- 可选模型首次使用时下载：`medium` 约 1.53 GB、`large-v3-turbo` 约 1.62 GB、`large-v3` 约 3.09 GB。
- 本地文件处理、已导入歌曲包播放和录音可以离线完成；YouTube / 哔哩哔哩搜索和下载需要网络，并受来源网站的登录和限流规则影响。
- 建议至少预留 5 GB；使用大模型或保留较多 MV 时建议 10 GB 以上。

## 已知限制

- 还没有逐字强制对齐；歌词时间来自字幕或识别结果。
- 下载和识别阶段在重试时仍可能重跑。
- 队列文件损坏时会保留原文件并阻止覆盖，但还没有专门的恢复界面。

# English

This is the first VocalFlow Studio build that is Developer ID signed and notarized by Apple. Drag it to Applications and double-click to open; you no longer need right-click → Open or Privacy & Security → Open Anyway.

It rolls up everything since beta.5: a fix for Add failing while search worked, lyrics that are checked against local recognition before use, recovery after interrupted or partly failed jobs, and a Chinese-first phone remote page. The installer still bundles the Python runtime, processing dependencies, `ffmpeg`, `yt-dlp`, the default Whisper small model and the UVR separator model. It works right after installation without Python, Homebrew, an HF Token or extra model downloads.

This is a prerelease test build. Clean-machine installation testing is still in progress.

## Changes

**Installation and first launch**
- Developer ID signed and notarized by Apple, with the notarization ticket stapled to the DMG.
- Fixes beta.5's downloader and separator carrying build-machine paths, which made Add fail while search worked. Adds the missing `audioread` package and separator model metadata.
- Electron 44.8.0 and updated dependencies with security advisories.

**Lyrics**
- Karaoke mode no longer skips vocal separation when platform captions exist.
- Auto mode prefers manual captions in the song's language and checks their text and rough timing against local recognition. On a text mismatch it uses the recognition draft; on a timing-only mismatch it keeps the text and marks the timing for review.

**Recovery after interruptions and failures**
- The room queue survives a restart. Interrupted jobs are marked failed and wait for you; they do not restart on their own.
- A retry with the same settings reuses the finished vocal separation only after its input, model and outputs pass verification.
- If separation finished but lyrics failed, the backing track stays in the library and can play without lyrics. The job still shows as failed and can be retried.
- Cancelled jobs are not treated as complete, and a failed redo does not replace an existing complete song.

**Phone remote**
- The page opened from the QR code is now search-first, in Chinese by default, with a one-tap English switch that is remembered.

**Messages**
- An HTTP 403 from a source site is no longer reported as "sign-in required".

## Models, network access and storage

- Bundled: `faster-whisper-small` (about 484 MB) and `UVR-MDX-NET-Inst_HQ_3.onnx` (about 67 MB).
- Optional models download on first use: `medium` about 1.53 GB, `large-v3-turbo` about 1.62 GB, `large-v3` about 3.09 GB.
- Local-file processing, playback of imported packages and recording work offline. YouTube/Bilibili search and downloads need network access and are subject to the source site's sign-in and rate limits.
- Keep at least 5 GB free, or 10 GB or more when using larger models or keeping many MVs.

## Known limitations

- No forced word-level alignment yet; lyric timing comes from captions or recognition.
- Download and recognition stages may still rerun on retry.
- A damaged queue file is preserved and never overwritten, but there is no dedicated recovery screen yet.

## First launch

1. Quit the old VocalFlow Studio.
2. Open the DMG and drag VocalFlow Studio to Applications, replacing the old copy.
3. Double-click it in Applications. If macOS still says it cannot verify the app, please send a screenshot; do not disable system security.
